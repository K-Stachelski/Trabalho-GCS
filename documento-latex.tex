\subsubsection{Resolução de conflitos de merge}

Para atender ao requisito de resolver pelo menos dois conflitos de merge, foram realizados dois testes utilizando branches diferentes. Em ambos os casos, duas branches modificaram a mesma linha de um arquivo, fazendo com que o Git identificasse conflitos de conteúdo durante a tentativa de merge.

\paragraph{Primeiro conflito}

O primeiro conflito ocorreu entre as branches \texttt{conflito-1-a} e \texttt{conflito-1-b}, que modificaram a mesma linha do arquivo \texttt{registro-conflitos.txt}. Ao executar o comando \texttt{git merge conflito-1-a}, o Git identificou um conflito de conteúdo e interrompeu o merge automático.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{Centopid/imagens/evidencias/Conflito 1.png}
    \caption{Identificação do primeiro conflito de merge pelo Git.}
    \label{fig:conflito1-terminal}
\end{figure}

A resolução foi realizada manualmente, preservando as informações das duas versões no arquivo final e removendo as marcações de conflito inseridas pelo Git. O resultado foi registrado no commit \texttt{49d6288}, com a mensagem \texttt{merge: resolve primeiro conflito de merge}.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{Centopid/imagens/evidencias/Conflito 2.png}
    \caption{Commit de resolução do primeiro conflito de merge.}
    \label{fig:conflito1-resolucao}
\end{figure}

\paragraph{Segundo conflito}

O segundo conflito ocorreu entre as branches \texttt{conflito-2-a} e \texttt{conflito-2-b}, que modificaram a mesma linha do arquivo \texttt{registro-segundo-conflito.txt}. Ao executar o comando \texttt{git merge conflito-2-a}, o Git também identificou um conflito de conteúdo e interrompeu o merge automático.

\begin{figure}[H]
    \centering

    \label{fig:conflito2-terminal}
\end{figure}

O conflito foi resolvido manualmente, mantendo as duas informações no arquivo final e removendo as marcações de conflito. A resolução foi registrada no commit \texttt{9b48b70}, com a mensagem \texttt{merge: resolve segundo conflito de merge}.
